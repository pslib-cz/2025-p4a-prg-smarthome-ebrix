Zprovoznění na Raspberry Pi

  1. Nainstaluj Home Assistant OS na Raspberry Pi
  2. Nastav ESP32 s ESPHome — připoj senzory AHT20, BMP280, PZEM-004T
  3. V HA přidej Long-Lived Access Token:
    Profil → Bezpečnost → Token
  4. Aktualizuj konstantu TOKEN v souboru
  5. Zkopíruj index.html do /config/www/
  6. Přístup přes: http://[HA_IP]:8123/local/index.html
